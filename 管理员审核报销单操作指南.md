## 二、详细操作步骤

### 步骤1：获取待审批报销单列表

**目的**：查看所有待审批的报销单

**API调用**：
```
GET /expense-reimbursement?approvalStatus=PENDING&page=1&size=10
```

**请求示例**：
```javascript
// uni-app 示例
uni.request({
    url: 'http://your-domain/api/expense-reimbursement',
    method: 'GET',
    header: {
        'Authorization': 'Bearer ' + token
    },
    data: {
        approvalStatus: 'PENDING',
        page: 1,
        size: 10
    },
    success: (res) => {
        console.log('待审批列表：', res.data.data.list);
        // 渲染列表到页面
    }
});
```

**响应数据关键字段**：
| 字段 | 说明 |
|------|------|
| reimbursementNumber | 报销单编号 |
| caseName | 案件名称 |
| applicantName | 申请人姓名 |
| totalAmount | 报销总金额 |
| reimbursementDate | 报销日期 |
| createTime | 创建时间 |

### 步骤2：查看报销单详情

**目的**：查看报销单完整信息，包括明细和附件

**API调用**：
```
GET /expense-reimbursement/{id}
```

**请求示例**：
```javascript
uni.request({
    url: 'http://your-domain/api/expense-reimbursement/' + reimbursementId,
    method: 'GET',
    header: {
        'Authorization': 'Bearer ' + token
    },
    success: (res) => {
        const detail = res.data.data;
        console.log('报销单详情：', detail);
        
        // 显示基本信息
        console.log('报销单号：', detail.reimbursementNumber);
        console.log('案件名称：', detail.caseName);
        console.log('申请人：', detail.applicantName);
        console.log('总金额：', detail.totalAmount);
        console.log('报销说明：', detail.description);
        
        // 显示报销明细
        detail.items.forEach(item => {
            console.log('费用项：', item.itemName, '金额：', item.itemAmount);
        });
        
        // 显示附件列表
        detail.attachments.forEach(att => {
            console.log('附件：', att.fileName);
        });
    }
});
```

### 步骤3：查看/下载附件材料

**目的**：审核报销凭证的真实性和完整性

#### 3.1 预览附件

**API调用**：
```
GET /expense-reimbursement/attachments/{attachmentId}/preview
```

**请求示例**：
```javascript
// 预览PDF或图片
const previewUrl = 'http://your-domain/api/expense-reimbursement/attachments/' 
    + attachmentId + '/preview';

// 方式1：使用webview打开
uni.navigateTo({
    url: '/pages/webview/webview?url=' + encodeURIComponent(previewUrl)
});

// 方式2：使用uni.previewImage预览图片
// 先获取文件信息判断类型
if (fileType.startsWith('image/')) {
    uni.previewImage({
        urls: [previewUrl]
    });
}

// 方式3：PDF使用系统浏览器打开
if (fileType === 'application/pdf') {
    plus.runtime.openFile(previewUrl);
}
```

#### 3.2 下载附件

**API调用**：
```
GET /expense-reimbursement/attachments/{attachmentId}/download
```

**请求示例**：
```javascript
const downloadUrl = 'http://your-domain/api/expense-reimbursement/attachments/' 
    + attachmentId + '/download';

uni.downloadFile({
    url: downloadUrl,
    header: {
        'Authorization': 'Bearer ' + token
    },
    success: (res) => {
        if (res.statusCode === 200) {
            // 保存到本地
            uni.saveFile({
                tempFilePath: res.tempFilePath,
                success: (saveRes) => {
                    uni.showToast({
                        title: '下载成功',
                        icon: 'success'
                    });
                }
            });
        }
    }
});
```

### 步骤4：审批报销单

**目的**：通过或拒绝报销申请

**API调用**：
```
POST /expense-reimbursement/{id}/approve
```

#### 4.1 审批通过

**请求示例**：
```javascript
uni.request({
    url: 'http://your-domain/api/expense-reimbursement/' + reimbursementId + '/approve',
    method: 'POST',
    header: {
        'Authorization': 'Bearer ' + token,
        'Content-Type': 'application/json'
    },
    data: {
        approvalStatus: 'APPROVED',
        approvalOpinion: '材料齐全，符合报销规定，同意报销。'
    },
    success: (res) => {
        if (res.data.code === 200) {
            uni.showToast({
                title: '审批通过',
                icon: 'success'
            });
            // 刷新列表或返回上一页
            uni.navigateBack();
        }
    }
});
```

#### 4.2 审批拒绝

**请求示例**：
```javascript
uni.request({
    url: 'http://your-domain/api/expense-reimbursement/' + reimbursementId + '/approve',
    method: 'POST',
    header: {
        'Authorization': 'Bearer ' + token,
        'Content-Type': 'application/json'
    },
    data: {
        approvalStatus: 'REJECTED',
        approvalOpinion: '发票信息不完整，缺少住宿发票，请补充后重新提交。'
    },
    success: (res) => {
        if (res.data.code === 200) {
            uni.showToast({
                title: '已拒绝',
                icon: 'success'
            });
            // 刷新列表或返回上一页
            uni.navigateBack();
        }
    }
});
```

## 四、审核要点清单

管理员在审核报销单时，应重点检查以下内容：

### 4.1 基本信息

- [ ] 报销单所属案件是否正确
- [ ] 申请人是否有权限申请该案件的报销
- [ ] 报销日期是否合理

### 4.2 费用明细

- [ ] 费用项目是否合理（与案件相关）
- [ ] 费用金额是否合理
- [ ] 明细说明是否清晰
- [ ] 总金额计算是否正确

### 4.3 附件材料

- [ ] 发票是否齐全
- [ ] 发票金额与报销金额是否一致
- [ ] 发票日期是否在合理范围内
- [ ] 发票抬头是否正确
- [ ] 其他凭证（行程单、住宿单等）是否完整

### 4.4 银行账户

- [ ] 收款账户信息是否正确
- [ ] 账户是否属于申请人或案件相关账户

## 六、错误处理

### 6.1 常见错误码

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| 401 | Token失效 | 重新登录获取Token |
| 403 | 无权限 | 检查用户是否有管理员权限 |
| 404 | 报销单不存在 | 刷新列表，检查ID是否正确 |
| 400 | 参数错误 | 检查请求参数格式 |

### 6.2 错误处理示例

```javascript
uni.request({
    // ... 其他参数
    fail: (err) => {
        console.error('请求失败：', err);
        uni.showToast({
            title: '网络请求失败',
            icon: 'none'
        });
    },
    success: (res) => {
        if (res.data.code !== 200) {
            // 业务错误
            if (res.data.code === 401) {
                // Token失效，跳转登录
                uni.navigateTo({
                    url: '/pages/login/login'
                });
            } else if (res.data.code === 403) {
                uni.showToast({
                    title: '无权限执行此操作',
                    icon: 'none'
                });
            } else {
                uni.showToast({
                    title: res.data.message || '操作失败',
                    icon: 'none'
                });
            }
        }
    }
});
```

## 七、注意事项

1. **权限要求**：只有ADMIN或SUPER_ADMIN角色的用户才能审批报销单

2. **状态限制**：只能审批状态为`PENDING`（待审批）的报销单

3. **审批不可逆**：审批操作一旦完成，无法撤销，请谨慎操作

4. **审批意见**：建议填写审批意见，便于申请人了解审批结果原因

5. **附件审核**：审批前务必查看所有附件材料，确保材料完整

6. **金额核对**：核对报销明细金额与附件发票金额是否一致

7. **并发处理**：如果多个管理员同时审批，后提交的可能失败（报销单已被审批）
