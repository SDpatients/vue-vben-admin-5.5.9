# 手机扫码上传文件处理流程总结

## 概述

本文档详细总结了 `/law/case-detail/{id}` 页面中**文书送达新增功能**的手机文件上传处理流程，为其他模块提供可参考的实现模式。

## 核心组件

### 1. FileUpload 组件
位置：[`FileUpload.vue`](file:///d:/Ai/vue-vben-admin-2/vue-vben-admin-5.5.9/apps/web-ele/src/views/law/case-detail/components/FileUpload.vue)

这是通用的文件上传组件，支持：
- 本地文件上传
- 服务器文件上传
- **手机扫码上传**
- 文件预览、下载、删除
- 文件重命名

### 2. 临时上传 Token API
位置：[`temp-upload.ts`](file:///d:/Ai/vue-vben-admin-2/vue-vben-admin-5.5.9/apps/web-ele/src/api/core/temp-upload.ts)

核心 API：
- `createTempUploadToken` - 创建临时上传 Token
- `getTempUploadFiles` - 获取 Token 下的已上传文件列表
- `transferTempFiles` - 将临时文件转移到业务
- `cancelTempUploadToken` - 取消 Token
- `mobileUploadFile` - 手机端单文件上传
- `mobileUploadBatch` - 手机端批量上传

### 3. 文件上传 API
位置：[`file.ts`](file:///d:/Ai/vue-vben-admin-2/vue-vben-admin-5.5.9/apps/web-ele/src/api/core/file.ts)

核心 API：
- `uploadFileApi` - 单文件上传
- `batchUploadFilesApi` - 批量文件上传
- `deleteFileApi` - 删除文件
- `downloadFileApi` - 下载文件
- `previewFileApi` - 预览文件

## 手机上传完整流程

### 阶段一：创建临时上传会话

#### 1.1 打开二维码弹窗
```typescript
const openMobileUploadDialog = async () => {
  // 1. 创建临时上传 Token
  const tokenResponse = await createTempUploadToken({
    bizType: props.bizType,        // 业务类型，如 'document'
    description: `${props.title || '文件'}上传`,
    expireMinutes: 30,              // 30 分钟过期
  });

  currentTempToken.value = tokenResponse.data.token;

  // 2. 检测本地 IP 地址
  if (mobileUploadConfig.value.autoDetect && !mobileUploadConfig.value.ip) {
    await detectLocalIP();
  }

  // 3. 生成二维码 URL
  let baseUrl = window.location.origin;
  const currentUrl = new URL(window.location.href);
  if (mobileUploadConfig.value.ip) {
    baseUrl = `http://${mobileUploadConfig.value.ip}:${mobileUploadConfig.value.port}`;
  } else {
    baseUrl = `http://${currentUrl.hostname}:${mobileUploadConfig.value.port}`;
  }

  // 4. 生成手机上传页面 URL（包含 token）
  const mobileUploadUrl = `${baseUrl}/mobile-upload?token=${encodeURIComponent(currentTempToken.value)}`;
  qrCodeUrl.value = mobileUploadUrl;
  showQrCodeDialog.value = true;

  // 5. 开始轮询获取手机上传的文件
  startTempFilePolling();
};
```

#### 1.2 IP 地址检测逻辑
```typescript
const detectLocalIP = async (): Promise<string> => {
  // 方法 0: 使用环境变量配置的 IP
  const configuredIP = import.meta.env.VITE_MOBILE_UPLOAD_IP;
  if (configuredIP && configuredIP !== 'localhost' && configuredIP !== '127.0.0.1') {
    return configuredIP;
  }

  // 方法 1: 检查当前主机名是否已经是有效 IP
  const hostname = window.location.hostname;
  const ipRegex = /^(\d{1,3}\.){3}\d{1,3}$/;
  if (ipRegex.test(hostname) && !hostname.startsWith('127.')) {
    return hostname;
  }

  // 方法 2: 通过 WebRTC 获取本地 IP
  const rtc = new RTCPeerConnection({ iceServers: [] });
  rtc.createDataChannel('');
  const offer = await rtc.createOffer();
  await rtc.setLocalDescription(offer);

  return new Promise<string>((resolve) => {
    rtc.onicecandidate = (event) => {
      if (event.candidate) {
        const candidate = event.candidate.candidate;
        const ipMatch = candidate.match(/(\d+\.\d+\.\d+\.\d+)/);
        if (ipMatch && ipMatch[1] && !ipMatch[1].startsWith('127.')) {
          resolve(ipMatch[1]);
          rtc.close();
          return;
        }
      } else {
        // ICE 候选收集完成
        resolve(useFallbackIP());
        rtc.close();
      }
    };

    // 超时处理（1 秒）
    setTimeout(() => {
      resolve(useFallbackIP());
      rtc.close();
    }, 1000);
  });
};

// 后备 IP 获取方法
const useFallbackIP = (): string => {
  const hostname = window.location.hostname;
  if (hostname && hostname !== 'localhost' && hostname !== '127.0.0.1') {
    return hostname;
  }
  return '192.168.0.151'; // 默认 IP
};
```

### 阶段二：轮询获取已上传文件

#### 2.1 轮询机制
```typescript
const startTempFilePolling = () => {
  // 清除之前的轮询
  if (tempFilePolling.value) {
    clearInterval(tempFilePolling.value);
    tempFilePolling.value = null;
  }

  // 立即执行一次
  pollTempFiles();

  // 每 3 秒轮询一次
  tempFilePolling.value = setInterval(async () => {
    await pollTempFiles();
  }, 3000);
};

const pollTempFiles = async () => {
  if (!currentTempToken.value) return;

  try {
    const response = await getTempUploadFiles(currentTempToken.value);
    
    if (response.code === 200 && response.data) {
      const newFiles = response.data;
      
      // 检查是否有新文件上传
      if (newFiles.length > mobileUploadedFiles.value.length) {
        const diffCount = newFiles.length - mobileUploadedFiles.value.length;
        ElMessage.success(`手机上传了 ${diffCount} 个新文件`);
        
        // 如果是本地模式，添加到本地文件列表
        if (isLocalMode.value) {
          // 将 TempUploadFile 转换为 LocalFileItem
          const newLocalFiles = newFiles
            .slice(mobileUploadedFiles.value.length)
            .map((tempFile) => ({
              file: new File([], tempFile.originalFileName, { type: tempFile.mimeType }),
              id: `mobile-${tempFile.id}`,
              originalFileName: tempFile.originalFileName,
              fileSize: tempFile.fileSize,
              fileExtension: tempFile.fileExtension,
              mimeType: tempFile.mimeType,
              uploadTime: tempFile.uploadTime,
            }));
          
          localFiles.value.push(...newLocalFiles);
          emit('local-files-change', localFiles.value);
        }
        
        // 触发事件通知父组件
        emit('mobile-files-uploaded', newFiles);
      }
      
      mobileUploadedFiles.value = newFiles;
    }
  } catch (error) {
    console.error('获取临时文件列表失败:', error);
  }
};
```

### 阶段三：文件转换与处理

#### 3.1 TempUploadFile 转 LocalFileItem
```typescript
interface TempUploadFile {
  id: number;
  originalFileName: string;
  fileSize: number;
  fileExtension: string;
  mimeType: string;
  uploadTime: string;
  token: string;
}

interface LocalFileItem {
  file: File;                    // 注意：手机上传的文件被创建为空的 File 对象
  id: string;                    // 格式：`mobile-${tempFile.id}`
  originalFileName: string;
  fileSize: number;
  fileExtension: string;
  mimeType: string;
  uploadTime: string;
}

// 转换逻辑
const newLocalFiles = newFiles
  .slice(mobileUploadedFiles.value.length)
  .map((tempFile) => ({
    file: new File([], tempFile.originalFileName, { type: tempFile.mimeType }),
    id: `mobile-${tempFile.id}`,
    originalFileName: tempFile.originalFileName,
    fileSize: tempFile.fileSize,
    fileExtension: tempFile.fileExtension,
    mimeType: tempFile.mimeType,
```

**关键点**：
- 手机上传的文件在本地模式中被转换为**空的 File 对象**（因为实际文件已在服务器）
- 使用 `mobile-` 前缀标识这些文件来自手机上传
- 保留文件的元数据（名称、大小、类型等）用于显示

#### 3.2 文件预览处理
```typescript
const handlePreview = async (file: FileItem | LocalFileItem | TempUploadFile) => {
  previewFile.value = file as FileItem | LocalFileItem;
  previewLoading.value = true;
  
  try {
    let blob: Blob;
    
    // 检查是否为从手机上传转换而来的文件
    const isMobileFile = typeof file.id === 'string' && file.id.startsWith('mobile-');
    
    // 对于从手机上传转换而来的文件，或者本地文件大小为 0 的文件，从服务器获取
    if ('file' in file && !isMobileFile && file.file.size > 0) {
      blob = file.file;  // 本地文件且有内容
    } else {
      // 从服务器获取文件数据
      const fileId = typeof file.id === 'string' 
        ? file.id.replace('mobile-', '')  // 去除前缀获取真实 ID
        : file.id;
      
      blob = await fileUploadRequestClient.get<Blob>(
        `/api/v1/file/preview/${fileId}`,
        { responseType: 'blob' }
      );
    }
    
    previewUrl.value = window.URL.createObjectURL(blob);
    showPreviewDialog.value = true;
  } catch (error) {
    console.error('文件预览失败:', error);
    ElMessage.error('文件预览失败');
  } finally {
    previewLoading.value = false;
  }
};
```

```typescript
const handleDownload = async (file: FileItem | LocalFileItem) => {

    ElMessage.error('文件下载失败');
```

### 阶段四：文件转移到业务

#### 4.1 转移临时文件
```typescript
const transferMobileFiles = async (bizId: number): Promise<TempUploadFile[]> => {
  if (!currentTempToken.value || mobileUploadedFiles.value.length === 0 || !bizId) {
    console.error('转移临时文件失败：缺少必要参数');
    return [];
  }

  try {
    const response = await transferTempFiles({
      token: currentTempToken.value,
      bizType: props.bizType,
      bizId: bizId.toString(),
    });

    if (response.code === 200 && response.data) {
      const transferredFiles = response.data;
      ElMessage.success(`成功转移 ${transferredFiles.length} 个文件到业务`);
      
      // 刷新文件列表
      await loadFiles();
      
      // 返回转移后的完整文件信息
      return transferredFiles;
    }
  } catch (error) {
    console.error('转移临时文件失败:', error);
    ElMessage.error('转移临时文件失败');
  }
  
  return [];
};
```

#### 4.2 关闭弹窗时的处理
```typescript
const closeQrCodeDialog = async () => {
  showQrCodeDialog.value = false;
  
  // 停止轮询
  if (tempFilePolling.value) {
    clearInterval(tempFilePolling.value);
    tempFilePolling.value = null;
  }
  
  let shouldCancelToken = true;
  
  // 如果有上传的文件
  if (mobileUploadedFiles.value.length > 0) {
    // 自动转移到业务（如果有有效的 bizId）
    if (props.bizId && props.bizId > 0) {
      console.log('有有效的 bizId，自动转移文件到业务:', props.bizId);
      await transferMobileFiles(props.bizId);
    } else {
      // 如果没有有效的 bizId，不取消 Token，以便稍后可以转移文件
      shouldCancelToken = false;
      ElMessage.info('文件已保存到临时存储，创建业务实体后可转移文件');
    }
  }
  
  // 取消 Token（只有当没有上传文件或已转移文件时）
  if (shouldCancelToken && currentTempToken.value) {
    try {
      await cancelTempUploadToken(currentTempToken.value);
    } catch (error) {
      console.error('取消 Token 失败:', error);
    }
    currentTempToken.value = '';
    mobileUploadedFiles.value = [];
  }
};
```

### 阶段五：本地模式下的文件上传

#### 5.1 批量上传本地文件
```typescript
const uploadLocalFiles = async (bizId: number): Promise<number[]> => {
  uploading.value = true;
  const uploadedFileIds: number[] = [];
  
  try {
    for (const localFile of localFiles.value) {
      try {
        // 跳过从手机上传转换而来的本地文件，因为它们是空的
        if (localFile.id.startsWith('mobile-')) {
          console.log(`跳过手机上传的文件 ${localFile.originalFileName}，请使用 transferMobileFiles 方法转移`);
          continue;
        }
        
        const response = await uploadFileApi(localFile.file, props.bizType, bizId);
        if (response.code === 200 && response.data) {
          uploadedFileIds.push(response.data.id);
        }
      } catch (error) {
        console.error(`文件 ${localFile.originalFileName} 上传失败:`, error);
      }
    }
    
    if (uploadedFileIds.length === localFiles.value.length) {
      ElMessage.success(`成功上传 ${uploadedFileIds.length} 个文件`);
    } else if (uploadedFileIds.length > 0) {
      ElMessage.warning(`成功上传 ${uploadedFileIds.length}/${localFiles.value.length} 个文件`);
    } else {
      ElMessage.info('没有需要上传的文件');
    }
    
    return uploadedFileIds;
  } finally {
    uploading.value = false;
  }
};
```

## 关键要点总结

### 1. 文件流转过程
```
手机扫码 → 临时存储 → 轮询获取 → 转换为 LocalFileItem → 转移到业务
```

### 2. 文件标识
- 手机上传文件：`id = 'mobile-' + tempFile.id`
- 本地文件：`id = 后端返回的文件 ID`

### 3. 文件处理策略
- **手机上传文件**：实际文件已在服务器，本地只有元数据，需要时从服务器下载
- **本地文件**：文件在本地，提交时需要上传到服务器

### 4. 本地模式（localMode）
- 启用后，文件先添加到 `localFiles` 数组
- 提交表单时统一处理上传
- 手机上传的文件会被转换为空的 `LocalFileItem`

### 5. Token 管理
- 创建：`createTempUploadToken` - 30 分钟有效期
- 轮询：每 3 秒查询一次已上传文件
- 转移：`transferTempFiles` - 将临时文件关联到业务
- 取消：`cancelTempUploadToken` - 清理未使用的 Token

### 6. IP 检测优先级
1. 环境变量 `VITE_MOBILE_UPLOAD_IP`
2. 当前页面主机名（如果是有效 IP）
3. WebRTC 获取本地 IP
4. 后备默认 IP `192.168.0.151`

## 注意事项

1. **Token 有效期**：临时 Token 30 分钟过期，需及时转移文件
2. **文件大小限制**：建议单个文件不超过 50MB
3. **网络环境**：确保手机和电脑在同一局域网
4. **端口配置**：可通过环境变量 `VITE_MOBILE_UPLOAD_IP` 指定 IP
5. **文件清理**：未转移的临时文件会被定期清理
6. **错误处理**：建议添加完善的错误处理和用户提示
